# Environment: code-observed settings

The backend uses Python, FastAPI, OpenCV, NumPy, PyJWT, ONVIF and optional Gemini/Web Push. `requirements.txt` is the dependency source. GitHub CI spans Python 3.9–3.13, installers, mobile builds and OpenCV 5.

## Private-first development
Set `SWARM_DETECTOR=local`, `SWARM_REMOTE=0`, leave `GEMINI_API_KEY` unset, use only synthetic videos/JPEGs. The installer can bind Uvicorn to `0.0.0.0`; tunnel-off does **not** mean LAN-inaccessible. Live use requires local firewall/permissions review. `config/env.template` is documentation; blank secrets must be securely generated by the human outside agent context before creating an actual `.env`.

## Code-backed variables
| Setting | Use | Code |
|---|---|---|
| `ADMIN_USER`, `ADMIN_PASS`, `JWT_SECRET`, `SWARM_TOKEN_DAYS` | login and JWT lifespan | `app/main.py` |
| `SWARM_DATA_DIR` | private camera/event/push state | `app/main.py`, `app/push.py` |
| `SWARM_PORT`, `SWARM_SCHEME`, `SWARM_HOME` | installer/listener | `install.sh` |
| `SWARM_DETECTOR`, `SWARM_LOCAL_MODEL`, `SWARM_MODEL_DIR` | inference mode/cache | `app/detector.py` |
| `SWARM_HOG_CONF`, `SWARM_PERSON_CONF` | local confidence | `app/detector.py` |
| `SWARM_CONFIRM_HITS`, `SWARM_ALERT_COOLDOWN` | alert debounce/cooldown | `app/detector.py` |
| `GEMINI_API_KEY`, `GEMINI_MODEL` | third-party JPEG inference | `app/detector.py` |
| `SWARM_REMOTE`, `SWARM_HTTPS` | public tunnel / local TLS | installer |
| `EMAIL_SMTP_SERVER`, `EMAIL_SMTP_PORT`, `EMAIL_SMTP_USER`, `EMAIL_SMTP_PASS`, `EMAIL_FROM` | email | `app/alert.py` |
| `SWARM_PUSH_SUB`, `SWARM_SERVER_SOUND` | VAPID identity / local alarm | `app/push.py`, `app/alert.py` |
| `SWARM_NO_START`, `SWARM_NO_SERVICE`, `SWARM_NO_ICON` | installer switches | `install.sh` |

## Commands
```sh
python scripts/validate_workspace.py
python -m pytest -q
```
Second command needs installed dependencies. `GET /health` proves basic process state, not camera functionality, safety of remote exposure or native app installation. Platform status requires actual GitHub Actions jobs and hardware verification where relevant.
