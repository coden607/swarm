# MISSION

swarm ships through a factory that stops for a person.

The factory plans one release at a time. A command validates it. A person tests and merges.

## Never

- Merge to the default branch without a person.
- Hand a repository `.env` to a model provider.
- Store someone else's full transcript.
- Let the factory edit this file, `FACTORY_RULES.md`, `harness/harness.config.json`, `harness/END-TO-END.md`, or `.factory/holdout/`.
- Ship an agent change straight to production.
